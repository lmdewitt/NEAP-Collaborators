## NEAP Collaborators

For now, dummy values are from [this document](https://docs.google.com/spreadsheets/d/17LrcAj5mCkFsZmxLHbMOAuDRJjjDmvpP-mOJxg-79KU/edit?gid=0#gid=0)

### Assume:

* Input will be the Google Spreadsheet output of a Google Form
* The spreadsheet column and values will be modeled on [this document](https://docs.google.com/document/d/196qg8miAepwdIGq5ys9pvybL9KrkOfWGxFsjYOZBmro/edit?tab=t.0)
* Collaborators will be able to check boxes to choose multiple values of
  + Organization
  + Region
  + Topical Expertise
  + Technical Skills
  + Products worked on
* The Google Form output for checkboxes is a comma separated list enclosed in quotation marks

### This page shows multiple ways we could organize the page.

* By Technical Expertise (right sidebar)
  + Tags are Technical Expertise and other filtering is done by using the search/Filter box or Order-by features.
  + Since the table is in view, the search box can easily be used to filter by interests (eg try "baking" or "California")
  + Note that by using the "Order By" dropdown, you can also sort a column in ascending or descending order

* By Multiple columns: Any number of column values can be combined into a set of tags in the right sidebar
